Help

    
  

  

    
Getting a GPS fix

    
Tap the crosshair button once to allow location access. The app asks for a quick Wi-Fi / network fix first (usually a second or two, 20–500 m) so you are on the map immediately, then refines it with satellites (3–10 m). On a laptop or indoors there is no satellite signal — the network fix is what you get; the phone/PC location service must be switched on. Outdoors, the first satellite fix can take 30–120 seconds without network assistance; keep the phone under open sky. If it stays on “No fix”, open the GPS panel and press Fast Wi-Fi fix.

    
Add your paper or PDF map

    
Maps → Add PDF or image. Choose a PDF (multi-page is fine; pick the page), a TIFF scan, or a
      photo/scan. The page is rendered on the device at high resolution, then georeferenced:

    
    
      
  • Rotate first if needed — sideways or upside-down scans: use Rotate image (90°/180°)
        before placing points.
    • 
      
  • Enter 2 control points — tap two landmarks on the image, then type their real coordinates (or paste
        lat, lon / UTM). Points far apart give the best result. Use Fine rotation for a
        slightly skewed scan.
    • 
      
  • Place & align on map — the map appears with your overlay on top: drag, pinch and twist to line it
        up with roads and ridges. The Size, Rotate and Fade sliders show exactly how big the
        overlay is (“… wide · … ft/px”), then lock it in.
    • 
    

    
If you know the paper scale (e.g. 1:24,000) choose it first — it makes aligning much quicker.

    
Offline use

    
The app itself is cached by the service worker after the first online load, so it opens with no signal. Base map tiles you view stay available; use Maps → Download view to pre-save tiles for the area you will hunt. PDF maps are stored on the device and need no signal at all.

    
Maps from your PC

    
When the HuntMap server is running on your computer, Maps → From your PC lists the maps stored there.
      Tap Download while you are on Wi-Fi: the map is copied onto this phone and keeps working with no signal.
      Aligning a downloaded map is saved back to the server, so other devices receive it already georeferenced.

    
Install on iPhone

    
Safari → Share → Add to Home Screen. Launch from the home screen for full-screen mode. iOS requires HTTPS for GPS, so open the app from the web address it was installed from (see README for hosting).

    
Batteries

    
GPS + screen is the biggest battery draw. Lower brightness, take short position checks, and use airplane mode (GPS still works) so the radio stops searching for towers. Keep screen awake holds the screen on while the app is open.

    
Accuracy warning

    
Phone GPS is typically 3–10 m accurate, sometimes 30 m under canopy. Never rely on this app alone for property boundaries, legal descriptions or safety-critical navigation. Carry a compass and paper map as backup, and check local hunting regulations.

GPS

    
  

  

    

    

      
      
    

    
The app asks for a quick Wi-Fi / network location first (seconds, 20–500 m), then refines it with satellites (3–10 m). Indoors, or on a laptop without GPS, only the network fix is possible — the phone/PC location service must be on for that. Fast Wi-Fi fix switches off the satellite step, which is the quickest way to get on the map inside a building.
